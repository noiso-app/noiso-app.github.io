Support

Help for playback, timers, and App Store review.

Use this page as the public Support URL for Noiso. It is intentionally simple and focused on the current app behavior.

What Noiso Includes

  • Seven bundled ambient presets.
  • Play and pause from the main screen.
  • Sleep timer with infinity, 30m, 1h, and 2h options.
  • Background playback and lock screen controls.

Common Questions

If playback does not start, confirm that the device volume is on and the app is allowed to play audio. For timer questions, note that pausing playback stops the active countdown without changing the selected timer type.

If the selected preset changes while playback is active, the new preset should start immediately.
